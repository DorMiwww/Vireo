## Phase 1 — MVP `[planned]`

> Goal: render a simple `.dac` file to JSON.

**Scope:**
- `vireo-core` — AST nodes, `VireoResult<T>`, `SourceLocation`
- `vireo-lexer` — tokenize basic `.dac` syntax
- `vireo-parser` — parse blocks, components, explicit properties
- `vireo-renderer-json` — emit JSON from AST
- `vireo-cli` — `vireo render <file.dac> --to json`

**Definition of done:** Example 1 and 2 from `EXAMPLES.md` render correctly to JSON.

**Out of scope for MVP:**
- Cross-file imports and references
- Variables and functions
- HTML and Figma renderers
- `vireo init` wizard

---

## Phase 2 — Layout & Composition `[planned]`

> Goal: auto layout, relational constraints, cross-file references.

**Scope:**
- Analyzer (`vireo-analysis`) — resolve `file.block.component` references, detect circular imports
- Layout constraints — Auto Layout, relational (`50%parent`, `parent.x + 16`)
- `vireo-renderer-html` — emit HTML/CSS from AST
- `vireo-cli` — `vireo render <file.dac> --to html`

**Definition of done:** Examples 3 and 4 from `EXAMPLES.md` render correctly to JSON and HTML.

---

## Phase 3 — Language Features `[planned]`

> Goal: variables, functions, basic conditionals — `.dac` becomes a real language.

**Scope:**
- Variables (`var primaryColor = #3B82F6`)
- Functions (`fun spacing(n: Int): Int`)
- Conditionals (`if $variant == "primary" then ... else ...`)
- Expression evaluator (custom mini-evaluator)

**Definition of done:** Examples 5 and 6 from `EXAMPLES.md` work correctly.

---

## Phase 4 — Figma Renderer `[planned]`

> Goal: render `.dac` designs directly into Figma.

**Scope:**
- Decide: Figma REST API vs Plugin transport
- `vireo-renderer-figma` — emit Figma API document from AST
- `vireo-cli` — `vireo render <file.dac> --to figma`
- Auth flow for Figma API token

**Definition of done:** Example 4 (login form) appears in Figma as a real design.

---

## Phase 5 — Init Wizard `[planned]`

> Goal: `vireo init` scaffolds a new project interactively.

**Scope:**
- CLI wizard — ask project name, choose renderers, generate project structure
- Example project generated by wizard
- GUI wizard (web-based) — planned, separate language (JS/TS)

---

## Phase 6 — Code Generation `[future]`

> Goal: reverse the pipeline — generate UI code from Vireo design.

**Scope:**
